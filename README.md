# Документация к приложению "GoTo"

## **О приложении** 
Данное приложение представляет собой систему каршеринга, стилизированное под мобильный телефон. Приложение разработано для оптимизации городской мобильности: оно позволяет пользователям быстро находить, бронировать и арендовывать транспортные средства для экономии времени при перемещении между локациями.

Приложение совмещает реализацию пользовательского интерфейса взаимодействия с базами данных, бронирование и аренду транспортного средства, просмотр информации о транспортном средстве, а также интерактивной карты с отображением на ней всех доступных поблизости транспортных средств. 

## Стек технологий

| Технология | Назначение |
|---|---|
| **C++** | основной язык разработки |
| **SFML 3.1** | графический интерфейс, отрисовка и обработка пользовательского ввода |
| **SQLite** | хранение данных приложения |
| **CMake** | система сборки проекта |
| **MapTiler API** | получение картографических данных |

## Инструкция по сборке

Клонирование репозитория
```bash
git clone https://github.com/ilyaMalin/-GoTo-car-sharing_system GoTo
cd GoTo
```

Создание конфигурации
```bash
cmake -S . -B build
```

Сборка проекта
```bash
cmake --build build --config Release
```

## Запуск

После успешной сборки запускаем исполняемый файл
```bash
./build/bin/GoTo.exe
```

**ВАЖНО: Для работы карты требуется подключение к интернету и настроенный API-ключ MapTiler.**
