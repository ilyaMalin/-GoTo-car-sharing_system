
# **Документация к ~~desktop-ному~~ приложению "GoTo"**

## **О приложении** 
Данное приложение представляет собой локальную систему каршеринга с графическим интерфейсом. Приложение разработано для оптимизации городской мобильности: оно позволяет пользователям быстро находить, бронировать и арендовывать транспортные средства для экономии времени при перемещении между локациями.

Система включает в себя интерактивную карту, модуль расчета стоимости аренды на базе различных тарифов и собственную подсистему хранения данных.
